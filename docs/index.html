The beast

Chimera is a CV-addressable breakbeat slicer: one beast stitched from two breaks. It loads one or two WAV loops into memory, cuts each into 4–32 slices, and fires slices from triggers, clocks, random pulses, CV, or MIDI. Every slice event rolls a set of effect dice — reverse, pitch, stutter, stretch, gate, filter, echo — so a static loop becomes a living break. Tag slices with drum roles and the beast can reassemble its own break into a groove template, or layer clean one-shots on top without touching the fx chain.

Inspired by amen (norns) and zeptocore/ectocore.

            ├── slices ── trims ── voice ── fx dice ─┤                  ├── drive ── crush ── OUT
WAV B GOAT ─┘                                        └──────────────────┘
                                       + beef one-shot (role-tagged, straight, ducks the original)

            slices: equal / transient · roles: Kick·Snare·Perc·Hat·Crash
            trims: level·rate·pitch·filter · dice: reverse·pitch·stutter·stretch·gate·filter·serpent
            always-on: backbeat weight · low-pass gate · crush · drive
Lion

Loop A. The master head: its slice count and role tags address the sequencer, CV and MIDI.

Goat

Loop B. The second head. Blend decides how often it butts in — or crossfades against Lion.

Serpent

The tail. A dub delay send, rolled per slice like any other effect. Dark, clock-chasing repeats.

Beef

Layer clean one-shots on top of role-tagged slices — a kick, a snare, whatever — untouched by the dice.

Getting started

  • Put stereo or mono WAVs on the SD card in sample folders.
  • Add the algorithm. Two specifications are chosen at this point and can't be changed without re-adding it: Max length (1–32 s, default 8 s, DRAM per loop) and Beef length (1–8 s, default 2 s, DRAM per one-shot slot — see Beef).
  • On the Lion page, choose a folder and sample. Loading is asynchronous; the display says Loading... until the break is in memory and sliced.
  • For a second break, set Loops to 2 on the Sample page, then pick Goat's folder and sample on the Goat page.
Filename convention

Name files name_<bpm>.wav — e.g. amen_174.wav or think_87.5.wav. Chimera reads the tempo from the filename and uses it for clock sync. No tempo suffix? Sync still works, one slice per clock tick.

Lion & Goat pages

Two breaks rarely match. Each head gets its own page — sample selection plus four pre-FX trims, applied at the voice before any effect dice roll. Use them to level, tune and tone-match unlike material.

TrimRangeWhat it does
Level−40 … +6 dBPer-loop gain, smoothly slewed. Also scales the loop's serpent echo send.
Rate25 … 400 %Varispeed. Speed and pitch move together, like a tape machine. Clock sync compensates for Rate, so a half-speed loop still lands on the grid.
Pitch−24 … +24 stSemitone tune. Free detune — sync leaves it alone, so you can tune Goat to Lion.
Filter−100 … +100One bipolar tone knob. Negative sweeps a low-pass down (18 kHz → 150 Hz); positive sweeps a high-pass up (20 Hz → 6 kHz); 0 is off.

The random per-event filter sweep (FX page) takes over the voice filter for events where it fires; the static trim covers everything else — including locked slices, which dodge the dice but keep their trims.

Slicing

Slices cuts each loop into 4, 8, 16 or 32 pieces. Slice mode decides where the knife falls:

  • Equal — a strict grid.
  • Transient — each grid point snaps to the strongest onset within ±40 % of a slice. Onset analysis runs in the background after load (analysing appears top-right); slices re-snap when it finishes.

Bars (1 or 2) tells Chimera how long the loop is musically. It drives the beat-aware random mode and the b2.3-style position labels on the display. 4/4 assumed — it's a breakbeat slicer.

Slices can also carry a drum-role tag — Kick, Snare, Perc, Hat or Crash — set per slice in the editor. Untagged slices play as normal; tagged ones feed three other features: Random's Role mode, Step mode's Pattern, and Beef's one-shot layering. See Role tags & grooves.

Slice editor

Press Button 3 to enter the editor: a zoomable waveform with movable slice points, Octatrack style. Press again to leave. Manual points, locks and role tags are saved with the preset.

Changing Slices or Slice mode re-slices from scratch and discards manual edits — deliberately.

Triggering

Six assignable CV inputs. Rising edges fire at 1 V, re-arm at 0.5 V.

InputBehaviour
SelectChooses the slice; sampled at the moment Trig fires. Linear: 0–5 V spans all slices. 1V/Oct: quantised to semitones, 0 V = C0 (standard Eurorack reference); Select offset sets which note is slice 1, one slice per semitone up. Default offset is C0 — patch a sequencer's pitch CV straight in and it lines up.
TrigFires the selected slice. With no Select input patched, each trig advances the step sequence instead.
RandomFires a random slice — see Random mode.
ClockAdvances the step sequence when Clock source is CV (the default), and teaches Chimera the tempo for sync, ratchets and the serpent.
ResetPulls the sequence back to slice 1.
RatchetA held gate retrigs the current slice at Ratchet div (1/1 … 1/8 of a clock tick).

Random mode

Free picks any slice. Beat jumps to the same position inside another beat, so downbeats land on downbeats. Role scans a boom-bap-ish template (kicks on downbeats, snares on backbeats, hats between) and picks a random slice carrying the tag that position expects — falling back to any slice when that role isn't tagged anywhere.

MIDI

Notes from 36 upward play slices directly — note 36 is slice 1, chromatically up. MIDI channel selects Omni or channels 1–16. Chimera also reads MIDI clock (24 PPQN, Start/Stop/Continue aware), but only steps the sequence off it when Clock source is set to MIDI — so the loop never runs off a host's clock unless you ask for it. In MIDI mode it drives Sync, the sequence step, ratchets and the serpent's tempo-chase alike; realtime clock bytes are channelless, so MIDI channel doesn't gate them.

Sequence & sync

Clock source

Picks which clock, if any, advances the sequence. Off — nothing steps on a clock; only explicit triggers play (Select + Trig, Random, MIDI notes, Ratchet). CV (default) — the patched Clock input steps. MIDI — incoming MIDI clock steps. Tempo for Sync is still measured either way, so Stretch/Repitch keep tracking a patched clock even when stepping is Off. Because the default is CV, the loop never plays off a host's MIDI clock unless you choose MIDI.

Step mode

Forward, Reverse, PingPong, Walk (drunk ±1), Shuffle (a random permutation, re-dealt each full cycle — every slice exactly once), Pattern (a 16-step groove template — see below).

Pattern

With Step mode set to Pattern, each clock tick advances through a 16-step groove template (Pattern: Boom-bap, 4-floor, Two-step, Half-time) mapped across the loop's bars. Every step expects a drum role; Chimera picks a random slice carrying that tag (falling back to any slice if the role isn't tagged anywhere), so a role-tagged break reassembles itself into the chosen groove. Blend, Break and the dice all still apply on top.

Sync

With a clock patched, Sync conforms each slice to the measured tempo:

  • Stretch — granular timestretch. Pitch stays put, duration locks to the grid.
  • Repitch — varispeed. Speed follows the clock, pitch rises and falls with it.

Clock div declares what a tick means (1/32 … 1 bar). Auto octave-normalises the ratio, so any power-of-two clock just works. The measured tempo shows top-left, as 174>172.3 — file tempo → clock tempo.

Effect dice

Every slice event rolls all dice at once, amen style. Each effect has a 0–100 % probability. Map a probability to a fader for controlled chaos, or to a gate (0/100) for manual punch-in.

DieEffect
ReverseSlice plays backwards.
Pitch up / downRepitch by Pitch amount semitones (1–24, default 12). Both fire → they cancel.
StutterRetrigs a sub-loop of the slice: Stutter div 1/2 … 1/16, or Random.
StretchGranular timestretch to Stretch amount (110–400 %). Stacks on top of sync stretch.
GateMPC-style tight chop to half length.
FilterA random LP or HP sweep across the slice, 200 Hz – 8 kHz, log-spaced ends.
SerpentSends the slice into the echo tail.

Break

The macro. Scales every probability at once: 50 = as set, 0 = all dice silent, 100 = all doubled. Map it to a big knob.

Backbeat

A second, rhythm-aware weight on top of Break. At 0 every event rolls normally. As it rises, downbeats (beats 1 & 3 in 4/4) are pulled toward zero probability, so at 100 % the dice only ever fire on backbeats (2 & 4) — downbeats always play straight, everything else keeps rolling. Good for keeping a groove's anchors steady while the chaos lives on the offbeats.

Tame

Hold Button 1 and the beast behaves — every die is suppressed while held. tamed shows on the display. Release to let it loose.

Always-on colour

Crush is an SP-1200-calibrated decimator — 50 is exactly 12 bits at 26.04 kHz. Drive is soft-clip saturation with automatic makeup gain. Both sit on the master bus, after the echo.

LPG is a per-slice low-pass gate (vactrol-style): every slice event strikes it fresh, sweeping the cutoff open then letting it decay — LPG decay sets how long (short pluck to full-slice length, ±10 % drift per strike so runs don't sound identical), LPG res adds resonance. Depth 0 is off; unlike the dice, this isn't a probability — once on, it's on every slice.

Blend, Quarrel, Serpent

Blend

With two loops loaded, Blend intermingles the heads. Two modes:

  • Chance — Blend is the probability that a slice event draws from Goat instead of Lion. Same slice index, other break.
  • Xfade — both heads play every slice; Blend is an equal-power crossfade between them.

Quarrel

The heads fight over the fader. Quarrel adds a random walk (±50) on top of Blend, leaking back toward centre. Higher = more violent disagreement.

Serpent

A dub delay tail. Slices that roll the Serpent die are sent into a feedback echo with darkened repeats. The delay time chases the clock at a dotted-eighth feel (¾ of a tick); unclocked it sits at 375 ms.

Role tags & grooves

Tag any slice with a drum role — Kick, Snare, Perc, Hat, Crash — in the slice editor: Pot C to set or cycle it, and a small letter (K/S/P/H/C) appears under the slice. Untagged slices are ignored by everything below and play exactly as before.

Three features read the tags:

  • Random mode: Role — scans a boom-bap-ish template (kicks on downbeats, snares on backbeats, hats between) and fires a random slice carrying the tag that position expects.
  • Step mode: Pattern — steps through a 16-step groove template (Boom-bap, 4-floor, Two-step, Half-time) the same way, but clocked instead of on Random pulses.
  • Beef — layers a clean one-shot on top of whichever role fires, regardless of how it fired.

Both Role and Pattern fall back to a plain random slice when the expected tag isn't present anywhere in the loop — an untagged break still plays, it just doesn't reassemble into the template.

Beef

Layer a one-shot sample on top of a role-tagged slice — beef up a thin kick, add a clap to the snare, whatever the break's missing. The Beef page holds one shared Beef folder plus a Sample, Level and Duck for each of the five roles.

Param (per role)RangeDefaultWhat it does
SampleNone / fileNonePicked from the shared Beef folder. None means the role is off — nothing loads, nothing plays.
Level0 … 100 %0One-shot volume. 0 means off even if a sample is assigned — existing presets stay silent on this feature until you turn it up.
Duck0 … 100 %0How hard the original slice ducks while its one-shot plays. The duck follows the one-shot's own envelope, so it attacks and releases in step with the hit rather than on a separate timer.

Whenever a slice fires, its role tag (from whichever loop is the canonical/master one) looks up that role's one-shot. If it's loaded and Level > 0, it plays — straight, from its own voice, completely bypassing the effect dice, Break, Tame, the per-loop static filter and the low-pass gate. It doesn't feed the serpent tail either. One beef hit chokes the previous one, same declick behaviour as the main voice.

Beef one-shots get their own DRAM budget, sized by the Beef length specification (1–8 s, default 2 s, chosen when you add the algorithm) — five slots' worth, regardless of how many roles you actually use.

The display

One strip per loop — waveform, slice markers, lock flags, the current slice underlined, a moving playhead. LION/GOAT sit centred in each strip with a 1px black halo, so they stay legible over the waveform. In Xfade blend mode each strip's waveform brightness tracks its live crossfade level — the quieter head visibly dims. Top-left shows tempo when synced, as 174>172.3. Top-right shows tamed or analysing when relevant — kept clear of the host's own top-right status icon.

The slice editor is a separate full-screen view: zoomed waveform, slice points, role letters, and a bottom control legend that brightens whichever control you last touched.

Field notes

  • Lock the one. Lock slice 1 (and the snare on beat 3) in the editor — the groove anchors itself no matter how hard the dice roll.
  • Gate the dice. Map Reverse or Stutter probability to a manual gate at 0/100 for zeptocore-style punch-ins.
  • Two breaks, one tempo. Trim Goat's Rate to match Lion's feel, then let Blend Chance at ~30 % swap hits between them.
  • Ratchet + Break. Hold a ratchet gate while sweeping Break up — instant fill, ends exactly on the next tick.
  • Tag first, then Pattern. Role tags do nothing until something reads them — tag a break's kicks/snares/hats before reaching for Random Role or Step mode Pattern, or you'll just get random slices.
  • Beef without surprises. Level and Sample both default to off, so dropping in a new Beef folder never changes an existing preset's sound until you raise a role's Level yourself.
  • Backbeat + dice. Push Backbeat toward 100 to keep 1 & 3 dead straight while the dice run wild on 2 & 4 — a groove that stays recognisable no matter how hot the FX get.
  • CPU. Light: roughly 2–3 % typical, ~5 % worst case (Xfade, all dice hot, drive and crush on). A brief analysis burst follows each sample load.
